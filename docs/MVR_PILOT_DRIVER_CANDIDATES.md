# PIOS — Кандидаты первых водителей пилота v1.0

Status: Draft — Product Owner-authority document (`PROJECT_CONSTITUTION.md` Section 7), Sprint 5 (Pilot Launch Preparation). Это шаблон для заполнения, а не готовый список — на момент создания реальные кандидаты ещё не названы.

**Важно про конфиденциальность.** Как только сюда впишут настоящие имена и контакты, этот файл будет содержать реальные персональные данные. Все остальные документы пилота (`MVR_PILOT_ACCEPTANCE_CRITERIA.md`, `MVR_PILOT_OPERATION_PLAN.md` и далее) намеренно избегали этого. Прежде чем заполнять и коммитить этот файл с настоящими данными, стоит решить отдельно: держать его в общем репозитории вместе с остальной документацией, или хранить отдельно, вне истории git (аналогично тому, как `.claude/CLAUDE.md` сейчас сознательно остаётся вне истории по другой причине). Это решение — не техническое, а про то, кто и как должен иметь доступ к личным данным реальных людей.

## На что смотреть при выборе (не обязательные критерии, ориентир)

- Готовность дать честную обратную связь, включая неудобную — пилоту нужны факты, не одобрение.
- Реально существующие, регулярные клиенты, которых водитель может пригласить хотя бы один раз в первые дни — без этого шаг 1 сценария (`MVR_FIRST_PILOT_SCENARIO.md`) не с кем провести.
- Достаточная уверенность с телефоном, чтобы открыть ссылку в браузере — установка приложений не нужна, но базовая уверенность с браузером телефона нужна.
- Разумно разный опыт (не только самые технически подкованные) — иначе обратная связь опишет только "лучший случай", а не то, с чем реально столкнётся типичный водитель.
